## 🔍 根本原因分析

### Bug 1：节点数据为空 - 时序问题

**问题代码位置：**
- `App.tsx` 第 604-620 行：`handleConfirmCreateAsset`
- `App.tsx` 第 718-738 行：`handleAddGroupToAssetLibrary`

**时间线（错误流程）：**

```
1. 用户框选节点
   → selectedNodeIds = ['node-1', 'node-2', 'node-3']
   
2. 用户点击"编组"按钮
   → 创建临时组
   → clearSelection() 被调用
   → selectedNodeIds = []  // ❌ 清空了！
   
3. 用户点击"添加到资产库"按钮
   → handleAddGroupToAssetLibrary 被调用
   → 打开对话框
   → 此时 selectedNodeIds 仍然是 []
   
4. 用户填写资产信息，点击"确认"
   → handleConfirmCreateAsset 被调用
   → 使用 selectedNodeIds 获取节点
   → selectedNodes = []  // ❌ 因为 selectedNodeIds 是空的
   → 创建的资产没有任何节点数据
```

**根本原因：**
- `handleConfirmCreateAsset` 依赖 `selectedNodeIds`
- 但在点击"编组"时，`clearSelection()` 已经清空了 `selectedNodeIds`
- 当用户点击"添加到资产库"时，`selectedNodeIds` 已经是空数组
- 所以创建的资产没有任何节点数据

**错误代码：**
```typescript
// App.tsx 第 604-620 行
const handleConfirmCreateAsset = useCallback((name: string, category: any) => {
  // ❌ 错误：使用 selectedNodeIds，但它已经被清空了
  const selectedNodes = Array.from(nodes.values()).filter(n => selectedNodeIds.includes(n.id));
  
  // ❌ 结果：selectedNodes = []
  const selectedConnections = connections.filter(conn => 
    selectedNodeIds.includes(conn.from) && selectedNodeIds.includes(conn.to)
  );
  
  // ❌ 创建的资产没有任何节点数据
  createAsset(name, category, selectedNodes, selectedConnections);
  
  console.log('[资产库] 资产创建成功', { name, category, nodesCount: selectedNodes.length });
  // 输出：nodesCount: 0  ❌
}, [selectedNodeIds, nodes, connections, createAsset, clearSelection]);
```

**正确的逻辑应该是：**
```typescript
// 在打开对话框时，保存节点数据
const handleAddGroupToAssetLibrary = useCallback(() => {
  if (!selectedGroupId) return;
  
  // ✅ 在这里获取节点数据，而不是在确认时
  const groupNodes = getGroupNodes(selectedGroupId);
  const groupConnections = connections.filter(conn => 
    groupNodes.some(n => n.id === conn.from) && groupNodes.some(n => n.id === conn.to)
  );
  
  // ✅ 保存到 state，供确认时使用
  setAssetDataToCreate({ nodes: groupNodes, connections: groupConnections });
  
  // 显示对话框
  setShowCreateAssetDialog(true);
}, [selectedGroupId, getGroupNodes, connections]);

// 在确认时，使用保存的数据
const handleConfirmCreateAsset = useCallback((name: string, category: any) => {
  if (!assetDataToCreate) return;
  
  // ✅ 使用保存的数据，而不是 selectedNodeIds
  createAsset(name, category, assetDataToCreate.nodes, assetDataToCreate.connections);
  
  // 清理
  setAssetDataToCreate(null);
  setShowCreateAssetDialog(false);
  clearSelection();
}, [assetDataToCreate, createAsset, clearSelection]);
```

### Bug 2：Blob URL 无法持久化

**问题代码位置：**
- `hooks/useAssetLibrary.ts` 第 42-54 行：`generateThumbnail`
- `hooks/useAssetLibrary.ts` 第 56-95 行：`createAsset`
- `hooks/useAssetLibrary.ts` 第 18-24 行：`deepCopyNodes`

**根本原因：**
- Blob URL 是浏览器临时生成的内存引用（`blob:http://localhost:5173/xxx`）
- Blob URL 只在当前页面会话中有效
- 页面刷新后，浏览器会释放所有 Blob URL
- localStorage 只能存储字符串，无法存储 Blob 对象本身

**数据流（错误流程）：**

```
1. 创建资产时
   → 节点数据包含 Blob URL（node.data.image = 'blob:http://...'）
   → generateThumbnail 返回 Blob URL
   → 保存到 localStorage（字符串形式）
   
2. 页面刷新
   → 浏览器释放所有 Blob URL
   → localStorage 中的 Blob URL 字符串仍然存在
   → 但是 Blob URL 已经失效（指向的内存已被释放）
   
3. 从 localStorage 恢复数据
   → 读取到 Blob URL 字符串
   → 尝试加载图片
   → 失败（404 Not Found）
   → 显示灰色占位符图标
```

**错误代码：**
```typescript
// hooks/useAssetLibrary.ts 第 42-54 行
const generateThumbnail = useCallback((nodes: AppNode[]): string => {
  // 简化实现：查找第一个有图片的节点
  for (const node of nodes) {
    if (node.data.image) {
      return node.data.image;  // ❌ 返回 Blob URL（无法持久化）
    }
    if (node.data.images && node.data.images.length > 0) {
      return node.data.images[0];  // ❌ 返回 Blob URL（无法持久化）
    }
  }
  
  return '';
}, []);
```

**正确的逻辑应该是：**
```typescript
// 1. 添加 Blob URL → Base64 转换函数
const convertBlobUrlToBase64 = async (blobUrl: string): Promise<string> => {
  const response = await fetch(blobUrl);
  const blob = await response.blob();
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onloadend = () => resolve(reader.result as string);
    reader.onerror = reject;
    reader.readAsDataURL(blob);
  });
};

// 2. 修改 generateThumbnail 为异步函数
const generateThumbnail = useCallback(async (nodes: AppNode[]): Promise<string> => {
  for (const node of nodes) {
    if (node.data.image) {
      // ✅ 如果是 Blob URL，转换为 Base64
      if (node.data.image.startsWith('blob:')) {
        return await convertBlobUrlToBase64(node.data.image);
      }
      return node.data.image;
    }
    if (node.data.images && node.data.images.length > 0) {
      const firstImage = node.data.images[0];
      // ✅ 如果是 Blob URL，转换为 Base64
      if (firstImage.startsWith('blob:')) {
        return await convertBlobUrlToBase64(firstImage);
      }
      return firstImage;
    }
  }
  return '';
}, []);

// 3. 修改 deepCopyNodes 为异步函数，转换所有 Blob URL
const deepCopyNodes = useCallback(async (nodes: AppNode[]): Promise<AppNode[]> => {
  return Promise.all(nodes.map(async (node) => {
    const copiedNode = {
      ...node,
      data: JSON.parse(JSON.stringify(node.data)),
      inputs: [...node.inputs],
    };
    
    // ✅ 转换 node.data.image
    if (copiedNode.data.image && copiedNode.data.image.startsWith('blob:')) {
      copiedNode.data.image = await convertBlobUrlToBase64(copiedNode.data.image);
    }
    
    // ✅ 转换 node.data.images
    if (copiedNode.data.images && Array.isArray(copiedNode.data.images)) {
      copiedNode.data.images = await Promise.all(
        copiedNode.data.images.map(async (url: string) => {
          if (url.startsWith('blob:')) {
            return await convertBlobUrlToBase64(url);
          }
          return url;
        })
      );
    }
    
    // ✅ 转换 node.data.gridImages
    if (copiedNode.data.gridImages && Array.isArray(copiedNode.data.gridImages)) {
      copiedNode.data.gridImages = await Promise.all(
        copiedNode.data.gridImages.map(async (url: string) => {
          if (url.startsWith('blob:')) {
            return await convertBlobUrlToBase64(url);
          }
          return url;
        })
      );
    }
    
    return copiedNode;
  }));
}, []);

// 4. 修改 createAsset 为异步函数
const createAsset = useCallback(async (
  name: string,
  category: AssetCategory,
  nodes: AppNode[],
  connections: Connection[],
  customThumbnail?: string

    name,
    category,
    thumbnail,  // ✅ 现在是 Base64，可以持久化
    thumbnailType,
    nodes: copiedNodes,  // ✅ 所有 Blob URL 已转换为 Base64
    connections: copiedConnections,
    createdAt: Date.now(),
    updatedAt: Date.now(),
  };
  
  addAsset(asset);
  
  return asset;
}, [addAsset, deepCopyNodes, deepCopyConnections, generateThumbnail]);
```

```typescript
// hooks/useAssetLibrary.ts 第 97 行
const useAsset = useCallback(async (
  assetId: string,
  position: { x: number; y: number },
  onAddNodes: (nodes: AppNode[]) => void,
  onAddConnections: (connections: Connection[]) => void
) => {
  console.log('[useAssetLibrary] 使用资产', { assetId, position });
  
  // 从 Store 获取资产数据
  const assets = useAssetLibraryStore.getState().assets;
  const asset = assets.find(a => a.id === assetId);
  
  if (!asset) {
    console.error('[useAssetLibrary] 资产不存在', { assetId });
    return;
  }
  
  // ✅ 等待异步转换完成
  const copiedNodes = await deepCopyNodes(asset.nodes);
  
  // 生成新的节点 ID 映射
  const idMap = new Map<string, string>();
  copiedNodes.forEach(node => {
    const newId = `node-${Date.now()}-${Math.random().toString(36).substr(2, 9)}`;
    idMap.set(node.id, newId);
  });
  
  // 计算资产的边界（用于定位）
  let minX = Infinity;
  let minY = Infinity;
  copiedNodes.forEach(node => {
    if (node.x < minX) minX = node.x;
    if (node.y < minY) minY = node.y;
  });
  
  // 调整节点位置和 ID
  const newNodes = copiedNodes.map(node => ({
    ...node,
    id: idMap.get(node.id)!,
    x: position.x + (node.x - minX),
    y: position.y + (node.y - minY),
  }));
  
  // 深拷贝连接数据并更新 ID
  const copiedConnections = deepCopyConnections(asset.connections);
  const newConnections = copiedConnections.map(conn => ({
    ...conn,
    from: idMap.get(conn.from) || conn.from,
    to: idMap.get(conn.to) || conn.to,
  }));
  
  // 添加节点和连接到画布
  onAddNodes(newNodes);
  onAddConnections(newConnections);
  
  console.log('[useAssetLibrary] 资产使用成功', {
    assetId,
    assetName: asset.name,
    nodesCount: newNodes.length,
    connectionsCount: newConnections.length,
    position,
  });
}, [deepCopyNodes, deepCopyConnections]);
```
