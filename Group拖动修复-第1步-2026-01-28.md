## 🔍 问题诊断

### 问题 1：参数顺序不匹配

**App.tsx 调用**:
```typescript
onMouseDown={(e) => { 
    startGroupDrag(e, g.id, g);  // 传递 (e, groupId, group)
}}
```

**useGroup Hook 原始签名**:
```typescript
const startGroupDrag = useCallback((groupId: string, e: React.MouseEvent) => {
    // 参数顺序：(groupId, e) ❌ 不匹配
}, [groups, getGroupNodes]);
```

**问题**：参数顺序不一致，导致 `groupId` 接收到 `MouseEvent`，`e` 接收到 `string`。

### 问题 2：缺少 scale 参数

**App.tsx 传递**:
```typescript
const { ... } = useGroup({
    groups,
    nodes,
    connections,
    scale,  // ✅ 传递了 scale
    ...
});
```

**useGroup Hook 原始接口**:
```typescript
interface UseGroupOptions {
    groups: Group[];
    nodes: Map<string, AppNode>;
    connections: Connection[];
    // scale: number;  // ❌ 被删除了
    ...
}
```

**问题**：`scale` 参数被删除，导致 TypeScript 报错。

### 问题 3：Transform 计算错误

**原始代码**:
```typescript
const updateGroupDrag = useCallback((e: MouseEvent, currentScale: number) => {
    const dx = (e.clientX - mouseStartX) / currentScale;  // ❌ 错误
    const dy = (e.clientY - mouseStartY) / currentScale;
    
    groupElement.style.transform = `translate(${dx}px, ${dy}px)`;
}, []);
```

**问题**：
- `dx` 和 `dy` 是世界坐标（除以 scale）
- 但 `transform` 需要屏幕坐标（不除以 scale）
- 结果：拖动时移动距离不对

## ✅ 修复方案

### 修复 1：调整参数顺序

```typescript
/**
 * 开始拖动分组
 * 
 * 注意：App.tsx 调用时传递 (e, groupId, group)
 */
const startGroupDrag = useCallback((e: React.MouseEvent, groupId: string, group: Group) => {
    e.stopPropagation();
    
    // 获取组内的所有节点
    const childNodes = getGroupNodes(groupId).map(n => ({
        id: n.id,
        startX: n.x,
        startY: n.y,
    }));

    dragGroupRef.current = {
        id: groupId,
        startX: group.x,
        startY: group.y,
        mouseStartX: e.clientX,
        mouseStartY: e.clientY,
        childNodes,
    };

    console.log('[useGroup] startGroupDrag:', {
        groupId,
        childNodesCount: childNodes.length,
        startPos: { x: group.x, y: group.y },
        mouseStart: { x: e.clientX, y: e.clientY },
    });
}, [getGroupNodes]);
```

**改进**：
- ✅ 参数顺序匹配 App.tsx 的调用
- ✅ 添加 `e.stopPropagation()` 防止事件冒泡
- ✅ 添加 console.log 方便调试

### 修复 3：正确的 Transform 计算

**拖动中（updateGroupDrag）**:
```typescript
const updateGroupDrag = useCallback((e: MouseEvent, currentScale: number) => {
    if (!dragGroupRef.current) return;

    const { id, mouseStartX, mouseStartY, childNodes } = dragGroupRef.current;

    // 计算偏移量（屏幕坐标）
    const screenDx = e.clientX - mouseStartX;  // ✅ 不除以 scale
    const screenDy = e.clientY - mouseStartY;

    // 使用 CSS transform 优化性能（直接操作 DOM）
    const groupElement = document.querySelector(`[data-group-id="${id}"]`) as HTMLElement;
    if (groupElement) {
        groupElement.style.transform = `translate(${screenDx}px, ${screenDy}px)`;
        groupElement.style.willChange = 'transform';
    }

    // 同时移动子节点
    childNodes.forEach((child: { id: string; startX: number; startY: number }) => {
        const nodeElement = document.querySelector(`[data-node-id="${child.id}"]`) as HTMLElement;
        if (nodeElement) {
            nodeElement.style.transform = `translate(${screenDx}px, ${screenDy}px)`;
            nodeElement.style.willChange = 'transform';
        }
    });

    console.log('[useGroup] updateGroupDrag:', {
        groupId: id,
        screenOffset: { dx: screenDx, dy: screenDy },
        childNodesCount: childNodes.length,
    });
}, []);
```

**拖动结束（endGroupDrag）**:
```typescript
const endGroupDrag = useCallback((e: MouseEvent, currentScale: number) => {
    if (!dragGroupRef.current) return;

    const { id, startX, startY, mouseStartX, mouseStartY, childNodes } = dragGroupRef.current;

    // 计算最终位置（世界坐标）
    const screenDx = e.clientX - mouseStartX;
    const screenDy = e.clientY - mouseStartY;
    const worldDx = screenDx / currentScale;  // ✅ 除以 scale 转换为世界坐标
    const worldDy = screenDy / currentScale;
    const finalX = startX + worldDx;
    const finalY = startY + worldDy;

    console.log('[useGroup] endGroupDrag:', {
        groupId: id,
        startPos: { x: startX, y: startY },
        screenOffset: { dx: screenDx, dy: screenDy },
        worldOffset: { dx: worldDx, dy: worldDy },
        finalPos: { x: finalX, y: finalY },
        scale: currentScale,
    });

    // 保存历史
    onSaveHistory();

    // 更新分组位置（使用 Store）
    onUpdateGroup(id, { x: finalX, y: finalY });

    // 更新子节点位置（使用 Store）
    childNodes.forEach((child: { id: string; startX: number; startY: number }) => {
        onUpdateNode(child.id, {
            x: child.startX + worldDx,
            y: child.startY + worldDy,
        });
    });

    // 清理 transform（让 React 接管）
    const groupElement = document.querySelector(`[data-group-id="${id}"]`) as HTMLElement;
    if (groupElement) {
        groupElement.style.transition = 'none';
        groupElement.style.transform = '';
        groupElement.style.willChange = 'auto';
        // 下一帧恢复 transition
        requestAnimationFrame(() => {
            if (groupElement) {
                groupElement.style.transition = '';
            }
        });
    }

    childNodes.forEach((child: { id: string; startX: number; startY: number }) => {
        const nodeElement = document.querySelector(`[data-node-id="${child.id}"]`) as HTMLElement;
        if (nodeElement) {
            nodeElement.style.transition = 'none';
            nodeElement.style.transform = '';
            nodeElement.style.willChange = 'auto';
            // 下一帧恢复 transition
            requestAnimationFrame(() => {
                if (nodeElement) {
                    nodeElement.style.transition = '';
                }
            });
        }
    });

    // 清理状态
    dragGroupRef.current = null;

    console.log('[useGroup] endGroupDrag: 完成');
}, [onSaveHistory, onUpdateGroup, onUpdateNode]);
```

**关键点**：
- ✅ 拖动中：使用屏幕坐标（不除以 scale）
- ✅ 拖动结束：转换为世界坐标（除以 scale）
- ✅ 清理 transform 后，下一帧恢复 transition（避免闪烁）

## 📝 技术细节

### 坐标系统

**屏幕坐标**：
- 鼠标事件的 `clientX`、`clientY`
- CSS `transform: translate(x, y)` 使用的坐标
- 不受画布缩放影响

**世界坐标**：
- 节点的 `x`、`y` 属性
- 受画布缩放影响
- 转换公式：`worldX = screenX / scale`

### 性能优化

**拖动中**：
- 直接操作 DOM（`element.style.transform`）
- 跳过 React 渲染（0 次重渲染）
- 使用 GPU 加速（`willChange: 'transform'`）

**拖动结束**：
- 更新 Store（触发 React 渲染）
- 清理 transform（让 React 接管）
- 恢复 transition（平滑动画）
