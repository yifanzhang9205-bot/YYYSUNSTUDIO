# 框选批量移动 + 组功能增强 - 实施方案 - 2026-02-08

## 问题描述

用户报告两个问题：

### 问题1：框选后无法批量移动 ❌
- **现状**：框选后节点显示选中状态，但无法像以前的组一样批量拖动
- **期望**：框选后可以直接拖动任意一个选中的节点，其他选中的节点跟随移动
- **需求文档**："不点击按钮时，只是临时选中，可以批量移动"

### 问题2：打组功能不完整 ❌
- **现状**：打组后只有"自动排列"一个功能
- **期望**：打组后应该有完整的组功能
  - ❌ 缺失：自定义颜色（7种颜色）
  - ❌ 缺失：水平布局
  - ❌ 缺失：解组功能

---

## 根本原因分析

### 问题1：useDrag Hook不支持多选拖动

**当前代码**（`hooks/useDrag.ts`）：
```typescript
const handleMouseDown = useCallback((
  e: React.MouseEvent,
  nodeId: string,
  node: AppNode,
  parentGroupId?: string | null,
  siblingNodeIds: string[] = []
) => {
  // 只处理单个节点的拖动
  dragRef.current = {
    id: nodeId,  // 只保存一个节点 ID
    startX: node.x,
    startY: node.y,
    // ...
  };
}, []);
```

**问题**：
- `dragRef.current`只保存一个节点的信息
- `handleMouseMove`只更新一个节点的位置
- 没有检查是否有其他选中的节点需要一起移动

### 问题2：GroupToolbar功能不完整

**当前代码**（`components/GroupToolbar.tsx`）：
```typescript
// 只有一个按钮：自动排列
<button onClick={() => onArrangeTopology(groupId)}>
  自动排列
</button>
```

**缺失功能**：
1. 自定义颜色按钮
2. 水平布局选项
3. 解组按钮

3. **修改 `handleMouseDown` 方法**：
```typescript
const handleMouseDown = useCallback((
  e: React.MouseEvent,
  nodeId: string,
  node: AppNode,
  parentGroupId?: string | null,
  siblingNodeIds: string[] = []
) => {
  e.stopPropagation();
  onSaveHistory();

  const element = e.currentTarget as HTMLElement;
  if (!element) return;

  // 🔥 检查是否是多选拖动
  const isMultiSelect = selectedNodeIds && selectedNodeIds.length > 1 && selectedNodeIds.includes(nodeId);

  let selectedNodesInfo: Array<{ id: string; startX: number; startY: number; element: HTMLElement | null }> = [];

  if (isMultiSelect && nodes) {
    // 🔥 收集所有选中节点的信息
    selectedNodesInfo = selectedNodeIds
      .filter(id => id !== nodeId) // 排除主拖动节点
      .map(id => {
        const n = nodes.get(id);
        if (!n) return null;
        
        // 查找节点的 DOM 元素
        const el = document.querySelector(`[data-node-id="${id}"]`) as HTMLElement;
        
        return {
          id,
          startX: n.x,
          startY: n.y,
          element: el,
        };
      })
      .filter(Boolean) as Array<{ id: string; startX: number; startY: number; element: HTMLElement | null }>;
  }

  // 初始化拖拽上下文
  dragRef.current = {
    id: nodeId,
    startX: node.x,
    startY: node.y,
    mouseStartX: e.clientX,
    mouseStartY: e.clientY,
    parentGroupId,
    siblingNodeIds,
    nodeWidth: node.width || 420,
    nodeHeight: node.height || 300,
    element,
    selectedNodes: selectedNodesInfo.length > 0 ? selectedNodesInfo : undefined, // 🔥 保存多选信息
  };

  setIsDragging(true);

  // GPU 加速优化
  requestAnimationFrame(() => {
    requestAnimationFrame(() => {
      if (!dragRef.current) return;
      
      const { element, selectedNodes } = dragRef.current;
      
      // 主节点
      if (element) {
        element.style.willChange = 'transform';
        element.style.transition = 'none';
      }
      
      // 🔥 其他选中节点
      if (selectedNodes) {
        selectedNodes.forEach(({ element: el }) => {
          if (el) {
            el.style.willChange = 'transform';
            el.style.transition = 'none';
          }
        });
      }
    });
  });
}, [onSaveHistory, selectedNodeIds, nodes]);
```

4. **修改 `handleMouseMove` 方法**：
```typescript
const handleMouseMove = (e: MouseEvent) => {
  if (!dragRef.current || !nodes) return;

  if (rafRef.current !== null) {
    return;
  }

  rafRef.current = requestAnimationFrame(() => {
    rafRef.current = null;

    if (!dragRef.current || !nodes) return;

    const { element, mouseStartX, mouseStartY, id, startX, startY, selectedNodes } = dragRef.current;
    
    // 计算偏移量
    const dx = (e.clientX - mouseStartX) / scale;
    const dy = (e.clientY - mouseStartY) / scale;

    // 计算新位置
    const newX = startX + dx;
    const newY = startY + dy;

    // 计算 transform 偏移
    const transformDx = newX - startX;
    const transformDy = newY - startY;

    // 🔥 更新主节点
    if (element) {
      element.style.transform = `translate(${transformDx}px, ${transformDy}px)`;
      element.style.setProperty('--drag-offset-x', `${transformDx}`);
      element.style.setProperty('--drag-offset-y', `${transformDy}`);
    }

    // 🔥 更新其他选中节点
    if (selectedNodes) {
      selectedNodes.forEach(({ element: el }) => {
        if (el) {
          el.style.transform = `translate(${transformDx}px, ${transformDy}px)`;
          el.style.setProperty('--drag-offset-x', `${transformDx}`);
          el.style.setProperty('--drag-offset-y', `${transformDy}`);
        }
      });
    }

    // 辅助线检测（只检测主节点）
    const currentNode = nodes.get(id);
    if (currentNode && helperLineRefs) {
      const lines = detectHelperLines(
        { ...currentNode, x: newX, y: newY },
        nodes,
        5
      );
      updateHelperLinesDom(lines);
    }
  });
};
```

5. **修改 `handleMouseUp` 方法**：
```typescript
const handleMouseUp = (e: MouseEvent) => {
  if (!dragRef.current) return;

  if (rafRef.current !== null) {
    cancelAnimationFrame(rafRef.current);
    rafRef.current = null;
  }

  const {
    id,
    startX,
    startY,
    mouseStartX,
    mouseStartY,
    element,
    selectedNodes,
  } = dragRef.current;

  // 计算最终位置
  const dx = (e.clientX - mouseStartX) / scale;
  const dy = (e.clientY - mouseStartY) / scale;
  const finalX = startX + dx;
  const finalY = startY + dy;

  // 🔥 清除主节点的 transform
  if (element) {
    const originalTransition = element.style.transition;
    element.style.transition = 'none';
    element.style.transform = '';
    element.style.removeProperty('--drag-offset-x');
    element.style.removeProperty('--drag-offset-y');
    element.style.willChange = '';
    element.offsetHeight;
    requestAnimationFrame(() => {
      if (element) {
        element.style.transition = originalTransition;
      }
    });
  }

  // 🔥 清除其他选中节点的 transform
  if (selectedNodes) {
    selectedNodes.forEach(({ element: el }) => {
      if (el) {
        const originalTransition = el.style.transition;
        el.style.transition = 'none';
        el.style.transform = '';
        el.style.removeProperty('--drag-offset-x');
        el.style.removeProperty('--drag-offset-y');
        el.style.willChange = '';
        el.offsetHeight;
        requestAnimationFrame(() => {
          if (el) {
            el.style.transition = originalTransition;
          }
        });
      }
    });
  }

  // 🔥 更新主节点的 Store
  onUpdateNode(id, { x: finalX, y: finalY });

  // 🔥 更新其他选中节点的 Store
  if (selectedNodes) {
    selectedNodes.forEach(({ id: nodeId, startX: sx, startY: sy }) => {
      const newX = sx + dx;
      const newY = sy + dy;
      onUpdateNode(nodeId, { x: newX, y: newY });
    });
  }

  // 隐藏辅助线
  hideHelperLines();

  // 清理上下文
  dragRef.current = null;
  setIsDragging(false);
};
```

const arrangeHorizontal = useCallback((groupId: string) => {
  const group = groups.get(groupId);
  if (!group) return;

  const groupNodes = Array.from(nodes.values()).filter(n => group.nodeIds.includes(n.id));
  if (groupNodes.length === 0) return;

  // 水平排列：从左到右
  const spacing = 80;
  let currentX = group.x + 20; // 组内边距
  const centerY = group.y + group.height / 2; // 垂直居中

  groupNodes.forEach(node => {
    const nodeHeight = node.height || 300;
    const newY = centerY - nodeHeight / 2; // 垂直居中对齐
    
    updateNode(node.id, { x: currentX, y: newY });
    currentX += (node.width || 420) + spacing;
  });

  // 调整组的大小
  const totalWidth = currentX - group.x + 20; // 加上右边距
  updateGroup(groupId, { width: totalWidth });
}, [groups, nodes, updateNode, updateGroup]);
```

2. **添加解组方法**：

const ungroup = useCallback((groupId: string) => {
  const group = groups.get(groupId);

  deleteGroup(groupId);

  selectGroup(null);
}, [groups, deleteGroup, selectGroup]);
```

## 验收标准

### 框选批量移动
- [ ] 框选2个或以上节点后，显示选中状态（蓝色边框）
- [ ] 拖动任意一个选中的节点，其他选中的节点跟随移动
- [ ] 移动过程中，所有节点保持相对位置不变
- [ ] 松手后，所有节点的位置正确更新到 Store
- [ ] 辅助线只检测主拖动节点（不检测跟随节点）

### 组功能增强
- [ ] 点击"颜色"按钮，显示7种颜色选择器
- [ ] 选择颜色后，组的背景和边框颜色改变
- [ ] 点击"自动排列"按钮，显示下拉菜单（水平 / 宫格）
- [ ] 选择"水平布局"，节点水平排列，垂直居中
- [ ] 选择"宫格布局"，节点按拓扑排序排列
- [ ] 点击"解组"按钮，组被删除，节点保留
- [ ] 所有功能流畅，无卡顿

## 技术细节

### 批量移动的性能优化

1. **Direct DOM 操作**：
   - 拖动时直接操作所有选中节点的 DOM
   - 不触发 React 渲染
   - 使用 `transform` 和 CSS 变量

2. **RAF 节流**：
   - 使用 `requestAnimationFrame` 节流
   - 避免每次 `mousemove` 都执行

3. **GPU 加速**：
   - 使用 `willChange: 'transform'`
   - 启用硬件加速

### 组颜色的实现

1. **颜色定义**：
   - 使用 Tailwind 的颜色系统
   - 背景：30% 透明度
   - 边框：100% 不透明

2. **颜色存储**：
   - 保存在 `Group` 对象的 `color` 字段
   - 默认值：`'default'`

3. **颜色渲染**：
   - 根据 `color` 字段动态生成样式
   - 使用内联样式（`style` prop）

## 风险和注意事项

### 风险1：批量移动性能问题
- **风险**：同时移动大量节点可能导致卡顿
- **缓解**：使用 Direct DOM 操作 + RAF 节流

### 风险2：辅助线检测复杂度
- **风险**：批量移动时，辅助线检测可能变慢
- **缓解**：只检测主拖动节点，不检测跟随节点

### 风险3：组颜色与现有样式冲突
- **风险**：组颜色可能与节点样式冲突
- **缓解**：使用半透明背景，确保节点可见
