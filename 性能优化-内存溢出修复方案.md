# 性能优化 - 内存溢出修复方案

## 问题分析

### 崩溃原因
**错误：** Render process gone - Out of Memory  
**触发：** 操作九宫格时崩溃  
**目标：** 支持 80-100 个节点同时运行

### 核心问题

#### 1. 图片数据过大（主要问题）⭐⭐⭐
```typescript
// 当前实现：直接存储原图
gridImages: base64Images,  // 21:9 高清图片，每张可能 5-10MB
gridImagesOriginal: base64Images,  // 又存了一份备份！
```

**问题：**
- 21:9 的 2K 图片，每张 base64 可能 5-10MB
- 九宫格 = 1 张 21:9 图片 = 5-10MB
- 存了两份（gridImages + gridImagesOriginal）= 10-20MB
- 10 个节点 = 100-200MB
- 100 个节点 = 1-2GB！💥

#### 2. Three.js 场景未清理
```typescript
// MultiAngleCameraNode.tsx
useEffect(() => {
    // 创建 Three.js 场景
    const renderer = new THREE.WebGLRenderer(...);
    const scene = new THREE.Scene();
    
    return () => {
        renderer.dispose();  // ✅ 有清理
        // 但是纹理、几何体、材质没有清理！❌
    };
}, []);
```

**问题：**
- 每个 3D 相机节点创建一个 Three.js 场景
- 纹理、几何体、材质占用大量显存
- 10 个节点 = 10 个场景 = 大量显存占用

#### 3. 没有图片懒加载
```typescript
// Node.tsx - 所有节点同时渲染
{nodes.map(node => (
    <Node key={node.id} node={node} ... />
))}
```

**问题：**
- 所有节点的图片同时加载到内存
- 即使节点不在视口内，图片也在内存中

#### 4. 没有内存清理机制
- 删除节点时，图片数据没有主动释放
- 切换工作流时，旧数据没有清理
- 没有 LRU 缓存机制

## 解决方案

### 优先级 1：图片压缩和缩略图（立即实施）⭐⭐⭐

#### 方案 A：只存储缩略图，需要时才加载原图

```typescript
// App.tsx - 修改图片存储逻辑
const base64Images = await downloadImagesInBatch(res);

// 生成缩略图（512px 宽度，压缩质量 0.7）
const thumbnails = await generateThumbnailsInBatch(base64Images, 512);

handleNodeUpdate(id, { 
    gridImages: thumbnails,  // 存储缩略图（每张约 50-100KB）
    gridImagesOriginal: undefined,  // 不存储原图备份
    image: thumbnails[0]
});

// 原图存储到 IndexedDB（异步，不占用内存）
await saveToIndexedDB(`grid-original-${id}`, base64Images);
```

**效果：**
- 缩略图：512px 宽度，每张约 50-100KB
- 九宫格 = 9 张缩略图 = 450-900KB（减少 90%）
- 100 个节点 = 45-90MB（可接受）

#### 方案 B：使用 WebP 格式压缩

```typescript
// workers/imageProcessor.ts - 添加 WebP 转换
const convertToWebP = (base64: string, quality: number = 0.8): Promise<string> => {
    return new Promise((resolve, reject) => {
        const img = new Image();
        img.onload = () => {
            const canvas = document.createElement('canvas');
            canvas.width = img.width;
            canvas.height = img.height;
            const ctx = canvas.getContext('2d')!;
            ctx.drawImage(img, 0, 0);
            
            // 转换为 WebP（压缩率更高）
            canvas.toBlob((blob) => {
                if (blob) {
                    const reader = new FileReader();
                    reader.onloadend = () => resolve(reader.result as string);
                    reader.readAsDataURL(blob);
                } else {
                    reject(new Error('WebP 转换失败'));
                }
            }, 'image/webp', quality);
        };
        img.src = base64;
    });
};
```

**效果：**
- WebP 比 JPEG/PNG 小 25-35%
- 进一步减少内存占用

### 优先级 3：图片懒加载（中期实施）⭐

#### 方案：虚拟滚动 + 懒加载

```typescript
// App.tsx - 只渲染视口内的节点
const [visibleNodeIds, setVisibleNodeIds] = useState<Set<string>>(new Set());

useEffect(() => {
    const updateVisibleNodes = () => {
        const viewportRect = {
            left: -pan.x / scale,
            top: -pan.y / scale,
            right: (-pan.x + window.innerWidth) / scale,
            bottom: (-pan.y + window.innerHeight) / scale,
        };
        
        const visible = new Set<string>();
        nodes.forEach(node => {
            const nodeRect = {
                left: node.x,
                top: node.y,
                right: node.x + (node.width || 400),
                bottom: node.y + (node.height || 300),
            };
            
            // 检查是否在视口内（带缓冲区）
            const buffer = 500;  // 500px 缓冲区
            if (
                nodeRect.right + buffer > viewportRect.left &&
                nodeRect.left - buffer < viewportRect.right &&
                nodeRect.bottom + buffer > viewportRect.top &&
                nodeRect.top - buffer < viewportRect.bottom
            ) {
                visible.add(node.id);
            }
        });
        
        setVisibleNodeIds(visible);
    };
    
    updateVisibleNodes();
    // 监听平移和缩放
}, [nodes, pan, scale]);

// 渲染时只渲染可见节点
{nodes.map(node => {
    const isVisible = visibleNodeIds.has(node.id);
    return (
        <Node
            key={node.id}
            node={node}
            isVisible={isVisible}  // 传递可见性
            ...
        />
    );
})}
```

```typescript
// Node.tsx - 根据可见性加载图片
export const Node: React.FC<NodeProps> = ({ node, isVisible, ... }) => {
    const [loadedImage, setLoadedImage] = useState<string | undefined>();
    
    useEffect(() => {
        if (isVisible && node.data.image) {
            // 可见时才加载图片
            setLoadedImage(node.data.image);
        } else {
            // 不可见时释放图片
            setLoadedImage(undefined);
        }
    }, [isVisible, node.data.image]);
    
    return (
        <div>
            {loadedImage && <img src={loadedImage} />}
        </div>
    );
};
```

**效果：**
- 只加载视口内的图片
- 视口外的图片不占用内存
- 支持更多节点

```typescript
// App.tsx
const deleteNodes = useCallback((ids: string[]) => {
    if (ids.length === 0) return;
    
    // 清理 IndexedDB 中的原图数据
    ids.forEach(async (id) => {
        await deleteFromIndexedDB(`grid-original-${id}`);
    });
    
    saveHistory(); 
    setNodes(p => p.filter(n => !ids.includes(n.id)).map(n => ({
        ...n, 
        inputs: n.inputs.filter(i => !ids.includes(i))
    }))); 
    setConnections(p => p.filter(c => !ids.includes(c.from) && !ids.includes(c.to))); 
    setSelectedNodeIds([]); 
}, [saveHistory]);
```

#### 方案 B：LRU 缓存机制

```typescript
// 限制内存中的图片数量
const MAX_IMAGES_IN_MEMORY = 50;
const imageCache = new Map<string, { data: string; lastUsed: number }>();

const getImage = (nodeId: string): string | undefined => {
    const cached = imageCache.get(nodeId);
    if (cached) {
        cached.lastUsed = Date.now();
        return cached.data;
    }
    
    // 从 IndexedDB 加载
    loadFromIndexedDB(`grid-original-${nodeId}`).then(data => {
        // 检查缓存大小
        if (imageCache.size >= MAX_IMAGES_IN_MEMORY) {
            // 删除最久未使用的
            const oldest = Array.from(imageCache.entries())
                .sort((a, b) => a[1].lastUsed - b[1].lastUsed)[0];
            imageCache.delete(oldest[0]);
        }
        
        imageCache.set(nodeId, { data, lastUsed: Date.now() });
    });
};
```

```typescript
            const { card, renderer, scene } = sceneRef.current;

                }
            });
```

4. **懒加载** - 只加载可见节点的图片
5. **内存管理** - LRU 缓存 + 主动清理
