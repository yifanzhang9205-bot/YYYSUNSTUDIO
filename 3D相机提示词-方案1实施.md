# 3D 相机提示词 - 方案 1 实施（相对化描述）

## 实施时间
2026-01-24

## 核心改动

### 问题分析

**原有问题：**
- UI 参数的语义是"相机相对于卡片的位置"
- 但提示词使用的是"角色的角度术语"（如 `Front View`, `Side View`）
- 导致语义不匹配

**举例说明：**
- UI：`horizontalAngle = 90°`（相机在卡片右侧）
- 旧提示词：`"Side View (right)"`（角色的右侧面）
- **矛盾**：相机在右侧看卡片正面，不等于看到角色的右侧面

### 解决方案：方案 1（相对化描述）

**核心思路：**
1. **保留距离术语**：`Medium Shot`, `Close-Up` 等描述画面构图，与相机位置无关
2. **保留高度术语**：`High Angle`, `Eye Level`, `Low Angle` 描述相机高度，没有歧义
3. **移除角度术语**：不再使用 `Front View`, `Side View` 等
4. **改用相机位置描述**：`camera panned left/right/centered`

### 2. 新增的函数

```typescript
// 新增：相机位置描述
const getCameraPositionDesc = (offset: -1 | 0 | 1): string => {
    if (offset === -1) return 'camera panned left';
    if (offset === 1) return 'camera panned right';
    return 'camera centered';
};
```

### 完整模板

```
IMPORTANT: Generate ONE SINGLE 21:9 image containing a 3×3 contact sheet grid.

[ROLE & TASK]
You are an expert CGI artist creating a character consistency contact sheet based on the provided INPUT IMAGE. Your task is to generate a single 21:9 image divided into 9 panels showing slight camera variations around the base position.

[CRITICAL CONSTRAINT: IMG2IMG FEATURE LOCKING]
Based strictly on the INPUT IMAGE, maintain perfect consistency across all 9 panels:
- Character Identity: LOCKED. EXACT same face, features, and expression.
- Outfit & Accessories: LOCKED. EXACT same clothing, colors, and textures.
- Lighting & Environment: LOCKED. Consistent lighting direction and mood.
- The ONLY variable: slight camera position shifts around the character.

[OUTPUT FORMAT]
- ONE single 21:9 image containing a 3×3 grid (9 panels with thin dividing lines)
- Style: Contact sheet / camera test

[BASE ANCHOR POINT - Panel 5]
Distance: {baseDistance} - character framing in the shot
Camera Height: {baseHeight} - camera vertical position
Camera Position: Centered - camera directly facing the character

This is your absolute reference. The character remains stationary; only the camera moves.

[CAMERA VARIATION MATRIX - 3D MICRO-ADJUSTMENTS]

Row 1 (Closer Distance + Elevated Camera):
Panel 1: {distance}, {height}, camera panned left
Panel 2: {distance}, {height}, camera centered
Panel 3: {distance}, {height}, camera panned right

Row 2 (Base Distance + Base Height):
Panel 4: {distance}, {height}, camera panned left
Panel 5: ★ BASE ANCHOR ★ {baseDistance}, {baseHeight}, camera centered
Panel 6: {distance}, {height}, camera panned right

Row 3 (Farther Distance + Lowered Camera):
Panel 7: {distance}, {height}, camera panned left
Panel 8: {distance}, {height}, camera centered
Panel 9: {distance}, {height}, camera panned right

[SPATIAL LOGIC]
- Vertical axis (rows): Camera distance changes (closer → base → farther)
- Horizontal axis (columns): Camera panning (left → center → right)
- The character stays in the same pose; the camera orbits around them

[RULES]
✅ Generate ONE image with 9 panels
✅ All variations are SUBTLE camera movements relative to Panel 5
✅ Maintain the illusion of a camera orbiting around a stationary character
✅ Keep character pose, lighting, and style identical

[NEGATIVE CONSTRAINTS]
❌ Do NOT change character pose between panels
❌ Do NOT change lighting direction between panels
❌ Do NOT generate 9 separate images
❌ Do NOT introduce new elements not in input image
❌ Do NOT rotate the character - only move the camera
```

## 关键改进点

### 1. 明确"角色固定，相机移动"

**新增说明：**
```
This is your absolute reference. The character remains stationary; only the camera moves.
```

```
The character stays in the same pose; the camera orbits around them.
```

```
❌ Do NOT rotate the character - only move the camera
```

### 2. 使用相对位置描述

**不再说：**
- `Front View`（角色的正面）
- `Side View`（角色的侧面）
- `Back View`（角色的背面）

**改为说：**
- `camera panned left`（相机向左偏移）
- `camera centered`（相机居中）
- `camera panned right`（相机向右偏移）

### 3. 保留有效的术语

**距离术语（保留）：**
- `Extreme Close-Up (ECU)`
- `Close-Up (CU)`
- `Medium Shot (MS)`
- `Medium Full Shot (MFS)`
- `Full Shot (FS)`
- `Long Shot (LS)`
- `Extreme Long Shot (ELS)`

**高度术语（保留）：**
- `High Angle`（俯视）
- `Eye Level`（平视）
- `Low Angle`（仰视）
