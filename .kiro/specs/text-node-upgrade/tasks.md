## 🔧 技术要点

### 必须遵守的规则

1. **三层架构**
   - UI Layer: 只负责渲染
   - Hooks Layer: 处理交互逻辑
   - Core Layer: 数据管理和纯计算

2. **不在 App.tsx 写业务逻辑**
   - 所有业务逻辑在 Hook 或 Store 中
   - App.tsx 只做组合和配置

3. **在 NodeRegistry 注册节点**
   - 所有节点类型必须注册
   - 注册信息完整

4. **使用 IndexedDB 存储图片**
   - 不使用 Base64 存储
   - 使用 Blob URL

5. **性能优化**
   - 所有组件使用 React.memo
   - 所有事件处理使用 useCallback
   - 输入防抖，API 节流

### 代码规范

- TypeScript 严格模式
- 所有函数添加注释
- 所有接口添加文档
- 变量命名清晰
- 代码格式统一
