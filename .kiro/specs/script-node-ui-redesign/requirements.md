# ScriptNode UI 重新设计 - 需求文档

## 📋 用户反馈

### 当前问题
1. ❌ 底部有多余的 AI 助手输入框（应该删除）
2. ❌ 红色错误提示"请输入您的创意"不应该显示
3. ❌ 整体 UI 不够专业、不够美观
4. ❌ 与界面其他部分风格不统一

### 用户期望
- ✅ 专业的视频制作工具风格
- ✅ 与界面整体风格一致（深色 + 蓝色强调）
- ✅ 简洁、直接、无多余元素
- ✅ 后续功能都遵循统一的设计规范

---

## 🎯 设计目标

### 1. 视觉风格
**参考产品**: DaVinci Resolve, Premiere Pro, Final Cut Pro

**核心特征**:
- 深色专业界面（#0a0a0a 背景）
- 蓝色强调色（#3b82f6 或类似）
- 微妙的边框和分隔线
- 清晰的层级关系
- 无过度装饰

### 2. 配色方案

```
背景层级:
- 画布背景: #0a0a0a
- 节点背景: #1a1a1a
- 卡片背景: #242424
- 悬停背景: #2a2a2a

文字:
- 主要文字: #ffffff (100%)
- 次要文字: #a0a0a0 (65%)
- 辅助文字: #666666 (40%)

强调色:
- 主要强调: #3b82f6 (蓝色)
- 成功: #10b981 (绿色)
- 警告: #f59e0b (橙色)
- 错误: #ef4444 (红色)

边框:
- 主要边框: #3b82f6 (蓝色，节点选中)
- 次要边框: #333333
- 分隔线: #222222
```

### 3. 字体规范

```
标题: 16px, font-weight: 600
正文: 14px, font-weight: 400
小字: 12px, font-weight: 400
标签: 11px, font-weight: 500, uppercase
```

### 4. 间距规范

```
内边距:
- 大: 24px
- 中: 16px
- 小: 12px
- 微: 8px

外边距:
- 组件间: 16px
- 卡片间: 12px
- 元素间: 8px
```

### 5. 圆角规范

```
- 节点: 12px
- 卡片: 8px
- 按钮: 6px
- 标签: 4px
```

## 🎨 ScriptNode 重新设计

### 空状态（Empty State）

```
┌─────────────────────────────────────────┐
│                                         │
│              [Film Icon]                │
│                                         │
│            创建影视剧本                  │
│                                         │
│     输入创意，AI 生成专业剧本结构        │
│                                         │
│          [开始创作] 按钮                 │
│                                         │
└─────────────────────────────────────────┘
```

**设计要点**:
- 居中布局
- 图标使用蓝色强调色
- 文字简洁清晰
- 只有一个主要按钮
- 无错误提示（除非真的出错）
- 无多余的输入框

### 折叠状态（Collapsed）

```
┌─────────────────────────────────────────┐
│ [Film] 剧本标题              [Edit] [▼] │
│ 一句话概述...                           │
├─────────────────────────────────────────┤
│  [Users]    [MapPin]    [Camera]        │
│    3 角色     2 场景      8 镜头         │
├─────────────────────────────────────────┤
│  [查看详情]           [生成工作流]       │
└─────────────────────────────────────────┘
```

**设计要点**:
- 紧凑的信息展示
- 图标 + 数字的统计卡片
- 两个主要操作按钮
- 可编辑标题

### 展开状态（Expanded）

```
┌─────────────────────────────────────────┐
│ [◀] 剧本标题                            │
├─────────────────────────────────────────┤
│ [角色] [场景] [分镜]                     │
├─────────────────────────────────────────┤
│                                         │
│  [角色卡片 1]                           │
│  [角色卡片 2]                           │
│  [角色卡片 3]                           │
│                                         │
└─────────────────────────────────────────┘
```

**设计要点**:
- Tab 切换清晰
- 卡片式布局
- 滚动区域明确
- 返回按钮明显

## 📐 技术实现

### Tailwind 类名规范

```typescript
// 背景
bg-[#1a1a1a]           // 节点背景
bg-[#242424]           // 卡片背景
bg-[#2a2a2a]           // 悬停背景

// 文字
text-white             // 主要文字
text-gray-400          // 次要文字
text-gray-600          // 辅助文字

// 边框
border-[#333333]       // 次要边框
border-blue-500        // 强调边框

// 按钮
bg-blue-500            // 主要按钮
hover:bg-blue-600      // 悬停状态
bg-[#242424]           // 次要按钮
hover:bg-[#2a2a2a]     // 悬停状态

// 圆角
rounded-xl             // 节点 (12px)
rounded-lg             // 卡片 (8px)
rounded-md             // 按钮 (6px)
rounded               // 标签 (4px)
```

## 🎯 验收标准

### 视觉验收
- [ ] 配色与界面整体一致
- [ ] 文字对比度清晰（WCAG AA 标准）
- [ ] 图标大小统一（20px）
- [ ] 间距统一（8px 倍数）
- [ ] 圆角统一

### 功能验收
- [ ] 空状态：只显示图标、文字、按钮
- [ ] 空状态：无错误提示
- [ ] 空状态：无多余输入框
- [ ] 点击"开始创作"弹出输入对话框
- [ ] 输入对话框样式统一
- [ ] 折叠状态信息清晰
- [ ] 展开状态 Tab 切换流畅

### 交互验收
- [ ] 按钮悬停有反馈
- [ ] 按钮点击有反馈
- [ ] 加载状态有动画
- [ ] 错误提示清晰（仅在真正出错时显示）

## 🔄 后续功能的设计规范

**所有新功能都遵循这个设计规范**:

1. 配色：使用上面定义的颜色
2. 字体：使用上面定义的大小和字重
3. 间距：使用 8px 倍数
4. 圆角：使用统一的圆角
5. 按钮：主要按钮用蓝色，次要按钮用灰色
6. 图标：统一 20px，strokeWidth={2}
