## 产品经理提问清单

### 核心问题
- [ ] **用户是谁？** 目标用户群体是什么？
- [ ] **解决什么问题？** 用户的痛点是什么？
- [ ] **为什么需要？** 现有方案有什么不足？
- [ ] **成功标准是什么？** 如何衡量功能是否成功？

### 使用场景
- [ ] **主要场景：** 用户在什么情况下会用这个功能？
- [ ] **频率：** 用户多久会用一次？
- [ ] **前置条件：** 使用前需要什么准备？
- [ ] **后续操作：** 使用后用户会做什么？

### 功能细节
- [ ] **输入：** 用户需要提供什么信息？
- [ ] **输出：** 用户会得到什么结果？
- [ ] **交互方式：** 点击、拖拽、快捷键？
- [ ] **反馈：** 如何告知用户操作成功/失败？

### 边界情况
- [ ] **空状态：** 没有数据时显示什么？
- [ ] **加载状态：** 处理中如何提示？
- [ ] **错误处理：** 失败了怎么办？
- [ ] **极限情况：** 数据量很大/很小时如何处理？

### 性能要求
- [ ] **响应时间：** 用户能接受多久的等待？
- [ ] **并发：** 能同时处理多少操作？
- [ ] **资源占用：** 内存/CPU 限制是什么？

### 兼容性
- [ ] **浏览器：** 需要支持哪些浏览器？
- [ ] **设备：** 桌面/平板/手机？
- [ ] **现有功能：** 会影响哪些现有功能？

### 可访问性
- [ ] **键盘导航：** 能用键盘完成所有操作吗？
- [ ] **屏幕阅读器：** 视障用户能用吗？
- [ ] **色盲友好：** 不依赖颜色传达信息？

### 安全性
- [ ] **权限：** 谁能使用这个功能？
- [ ] **数据保护：** 敏感数据如何处理？
- [ ] **输入验证：** 如何防止恶意输入？
