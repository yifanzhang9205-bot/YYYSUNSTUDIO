# Coze AI 导演助手 - 需求文档

## 1. 功能概述

将 Coze（扣子）智能体集成到 SunStudio，作为专业的 AI 导演助手，帮助用户优化提示词、规划工作流、生成专业的影视制作内容。

**核心定位**：AI 协作工具，而非 AI 替代工具（F1 赛车模式）

---

## 2. 商业价值

### 解决的问题
1. **提示词质量低** - 用户不知道如何写出高质量的图片/视频生成提示词
2. **工作流混乱** - 从灵感到成片缺乏专业的制作流程指导
3. **重复劳动多** - 批量调整风格、镜头语言等操作繁琐
4. **学习成本高** - 不了解专业影视制作的术语和规范

### 目标用户
- 有创意但缺乏专业技能的内容创作者
- 需要快速产出高质量视频的自媒体从业者
- 想要学习专业影视制作流程的爱好者

### 成功指标
- 提示词优化后的图片/视频质量提升 50%+
- 用户完成一个完整项目的时间缩短 30%+
- 用户对 AI 建议的采纳率 > 60%
- 用户留存率提升 20%+

---

## 3. 用户场景

### 主场景：专业影视制作工作流

**标准流程（基于行业最佳实践）：**


```
1. 创意开发 (Development)
   ├─ 灵感/概念
   ├─ 故事大纲
   └─ 剧本初稿

2. 剧本分解 (Script Breakdown) ⭐ AI 核心能力
   ├─ 场景分析
   ├─ 角色提取
   ├─ 道具/场景列表
   └─ 技术需求标注

3. 分镜设计 (Storyboarding) ⭐ AI 核心能力
   ├─ 镜头列表 (Shot List)
   ├─ 镜头类型（特写/中景/全景）
   ├─ 机位角度（平视/俯视/仰视）
   ├─ 运镜方式（静止/推进/跟随）
   └─ 视觉描述

4. 资产生成 (Asset Creation)
   ├─ 角色参考图 ⭐ AI 优化提示词
   ├─ 场景参考图 ⭐ AI 优化提示词
   └─ 道具/氛围图

5. 镜头生成 (Shot Production)
   ├─ 按分镜生成图片 ⭐ AI 优化提示词
   ├─ 图片转视频
   └─ 多角度相机调整

6. 后期制作 (Post-Production)
   ├─ 视频剪辑/拼接
   ├─ 音频添加
   └─ 特效/调色
```

### 用户旅程示例

**场景 A：新手用户 - 从零开始**
1. 用户打开聊天窗口，输入："我想做一个赛博朋克风格的短片"
2. AI 导演询问：时长？主题？情绪？目标受众？
3. AI 生成剧本大纲（3-5 个场景）
4. 用户确认后，AI 自动生成分镜列表（10-15 个镜头）
5. 用户点击"生成工作流"，AI 自动创建节点并连接
6. 用户逐个节点生成内容，AI 实时优化提示词

**场景 B：进阶用户 - 提示词优化**
1. 用户在图片生成节点输入："一个机器人"
2. 用户点击节点上的"✨ AI 优化"按钮
3. AI 弹出优化建议：
   - 简洁版："humanoid robot, neon lights, cyberpunk"
   - 标准版："Medium shot of a humanoid robot..."
   - 电影级："In the rain-soaked streets of Neo Tokyo..."
4. 用户选择一个版本，一键应用

**场景 C：专业用户 - 批量操作**
1. 用户选中 10 个图片节点
2. 右键 → "AI 批量优化"
3. AI 分析：统一风格、色调、镜头语言
4. 用户确认后，AI 批量更新所有节点的提示词

## 4. 功能规格

### 4.1 核心功能：智能提示词工程师


#### 输入
- 用户的简单描述（文本）
- 可选：参考图片、风格关键词、情绪标签
- 可选：节点类型（图片/视频/角色/场景）

#### 输出（结构化 JSON）
```json
{
  "versions": {
    "concise": "关键词列表，逗号分隔",
    "standard": "结构化提示词（主体+环境+光线+风格+质量）",
    "cinematic": "叙事性描述，富有感染力"
  },
  "negativePrompt": "模糊、畸形、低质量、水印...",
  "parameters": {
    "aspectRatio": "16:9",
    "shotType": "Medium Shot",
    "cameraAngle": "Eye Level",
    "lighting": "Cinematic",
    "style": "Photorealistic"
  },
  "reasoning": "为什么这样优化的解释"
}
```

#### 验证规则
- 简洁版：≤ 50 字符
- 标准版：100-300 字符
- 电影级：300-500 字符
- 负面提示词：必须包含常见问题（模糊、畸形等）
- 参数：必须符合西瓜皮 API 规范

---

#### 输入
- 用户的剧本/故事大纲（文本）
- 可选：目标时长、镜头数量、风格偏好

#### 输出（结构化 JSON）
```json
{
  "title": "短片标题",
  "logline": "一句话概述",
  "theme": "主题/情绪",
  "characters": [
    {
      "name": "角色名",
      "description": "外貌描述",
      "personality": "性格特点",
      "visualKeywords": ["关键词1", "关键词2"]
    }
  ],
  "scenes": [
    {
      "sceneNumber": 1,
      "location": "INT. 赛博朋克酒吧",
      "timeOfDay": "夜晚",
      "mood": "神秘、紧张",
      "description": "场景描述",
      "visualKeywords": ["霓虹灯", "烟雾", "暗色调"]
    }
  ],
  "shots": [
    {
      "shotNumber": 1,
      "sceneNumber": 1,
      "shotType": "Wide Shot",
      "cameraAngle": "High Angle",
      "cameraMovement": "Static",
      "duration": 3,
      "characters": ["主角"],
      "action": "主角推门进入酒吧",
      "dialogue": "可选台词",
      "visualDescription": "详细的视觉描述",
      "imagePrompt": "优化后的图片生成提示词"
    }
  ]
}
```

### 4.3 核心功能：工作流规划师

#### 输入
- 剧本分解结果（JSON）
- 用户偏好（是否需要角色参考、场景参考等）

#### 输出
- 节点创建指令列表
- 节点连接关系
- 分组建议

#### 示例输出
```json
{
  "nodes": [
    {
      "type": "STORY_STUDIO",
      "title": "剧本：赛博朋克短片",
      "position": { "x": 100, "y": 100 },
      "data": { "storyData": "..." }
    },
    {
      "type": "CHARACTER_REFERENCE",
      "title": "角色：主角机器人",
      "position": { "x": 400, "y": 100 },
      "data": { "prompt": "优化后的提示词" }
    }

    { "from": "node-1", "to": "node-2" }

  "groups": [
    {
      "title": "场景 1：酒吧",
      "nodeIds": ["node-3", "node-4", "node-5"]
    }
  ]
}
```

## 6. 交互流程

### 流程 1：提示词优化

```
1. 用户在节点输入："一个机器人"
2. 用户点击节点上的"✨ AI 优化"按钮
3. 系统发送请求到 Coze API：
   {
     "userInput": "一个机器人",
     "nodeType": "IMAGE_GENERATOR",
     "context": {
       "aspectRatio": "16:9",
       "style": "cyberpunk"
     }
   }
4. Coze 返回优化结果（JSON）
5. 系统弹出优化结果卡片
6. 用户选择一个版本
7. 系统更新节点的 prompt 字段
8. 用户点击"生成"按钮
```

---

### 流程 2：剧本分解 → 工作流生成

```
1. 用户在聊天窗口输入剧本
2. 用户点击"生成分镜列表"快捷指令
3. 系统发送请求到 Coze API
4. Coze 返回剧本分解结果（JSON）
5. 系统解析 JSON，生成工作流预览
6. 用户确认
7. 系统批量创建节点：
   - 创建 STORY_STUDIO 节点（存储剧本数据）
   - 为每个角色创建 CHARACTER_REFERENCE 节点
   - 为每个场景创建 SCENE_REFERENCE 节点
   - 为每个镜头创建 STORYBOARD_SHOT 节点
8. 系统创建连接关系
9. 系统创建分组
10. 系统自动排列节点（拓扑排序）
```


---

### 流程 3：批量优化

```
1. 用户选中 10 个图片节点
2. 用户右键 → "AI 批量优化" → "统一风格"
3. 系统收集所有节点的提示词
4. 系统发送请求到 Coze API：
   {
     "prompts": ["prompt1", "prompt2", ...],
     "optimizationGoal": "unify_style",
     "targetStyle": "cyberpunk"
   }
5. Coze 分析并返回优化后的提示词列表
6. 系统弹出预览对话框（显示变更对比）
7. 用户确认
8. 系统批量更新节点
```

## 7. 错误处理

| 错误类型 | 触发条件 | 提示信息 | 用户操作 |
|---------|---------|---------|---------|
| API 密钥未配置 | 首次使用 | "请先配置 Coze API Key" | 打开设置面板 |
| API 调用失败 | 网络错误/服务器错误 | "AI 服务暂时不可用，请稍后重试" | 重试/取消 |
| 返回格式错误 | JSON 解析失败 | "AI 返回了无效的数据，请重试" | 重试/取消 |
| 提示词过长 | 超过 API 限制 | "提示词过长，请简化后重试" | 修改输入 |
| 配额不足 | API 配额用尽 | "API 配额不足，请充值后继续" | 打开充值页面 |
| 超时 | 请求超过 30 秒 | "请求超时，请检查网络连接" | 重试/取消 |

## 8. 性能要求

- **响应时间**：
  - 提示词优化：< 3 秒
  - 剧本分解：< 10 秒
  - 工作流生成：< 5 秒（不含节点渲染）
  - 批量优化：< 2 秒/节点

- **内存占用**：
  - 聊天历史：最多保存 50 条消息
  - 单次请求：< 5 MB
  - 缓存：< 50 MB

- **并发支持**：
  - 同时最多 3 个 API 请求
  - 队列等待时显示进度

---

## 9. 兼容性

- **浏览器**：Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **设备**：桌面（主要）、平板（次要）
- **屏幕分辨率**：1920x1080（推荐）、1366x768（最低）
- **网络**：需要稳定的互联网连接

---

## 10. 安全性

### API 密钥管理
- 存储位置：localStorage（加密）
- 传输方式：HTTPS
- 不在日志中记录完整密钥

### 数据隐私
- 用户的剧本/提示词会发送到 Coze 服务器
- 不会存储在 SunStudio 服务器
- 用户可以随时清除本地聊天历史

### 输入验证
- 过滤恶意脚本（XSS）
- 限制输入长度（< 10000 字符）
- 限制 API 调用频率（防止滥用）

## 13. 风险和依赖

### 风险 1：Coze API 不稳定
- **描述**：Coze 服务可能宕机或限流
- **影响**：用户无法使用 AI 功能
- **缓解方案**：
  - 添加重试机制（最多 3 次）
  - 显示友好的错误提示
  - 提供备用方案（使用 BLTCY API）

### 风险 2：返回格式不一致
- **描述**：Coze 可能返回非预期的 JSON 格式
- **影响**：解析失败，功能不可用
- **缓解方案**：
  - 严格的 JSON Schema 验证
  - 容错处理（部分字段缺失时使用默认值）
  - 详细的错误日志

### 风险 3：成本控制
- **描述**：用户频繁调用 API 导致成本过高
- **影响**：运营成本增加
- **缓解方案**：
  - 限制调用频率（每分钟最多 10 次）
  - 缓存常见请求
  - 提供配额提醒

### 依赖 1：Coze 平台
- **描述**：依赖 Coze 提供 API 服务
- **备选方案**：集成其他 AI 服务（OpenAI、Claude）

### 依赖 2：现有节点系统
- **描述**：需要现有的节点类型支持
- **备选方案**：如果节点类型不足，先扩展节点系统

## 16. 附录：专业术语表

### 镜头类型 (Shot Type)
- **Extreme Wide Shot (EWS)** - 极远景：展示整个环境
- **Wide Shot (WS)** - 远景：展示完整场景
- **Full Shot (FS)** - 全景：展示完整人物
- **Medium Shot (MS)** - 中景：腰部以上
- **Close-Up (CU)** - 特写：头部
- **Extreme Close-Up (ECU)** - 大特写：眼睛/细节

### 机位角度 (Camera Angle)
- **Eye Level** - 平视：与主体平行
- **High Angle** - 俯视：从上往下
- **Low Angle** - 仰视：从下往上
- **Bird's Eye View** - 鸟瞰：正上方
- **Dutch Angle** - 荷兰角：倾斜

### 运镜方式 (Camera Movement)
- **Static** - 静止：固定机位
- **Pan** - 摇镜：水平旋转
- **Tilt** - 俯仰：垂直旋转
- **Dolly** - 推拉：前后移动
- **Track** - 跟随：横向移动
- **Crane** - 升降：垂直移动
- **Handheld** - 手持：自然晃动
