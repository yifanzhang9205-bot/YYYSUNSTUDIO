## 🚀 配置步骤（5 分钟完成）

### 第 1 步：选择模型
1. 进入扣子平台
2. 创建新智能体（或编辑现有的）
3. 在模型选择中找到 **Doubao-Seed-1.8**
4. 点击选择

### 第 2 步：调整参数
1. 找到"参数设置"或"高级设置"
2. **重复惩罚**：从 0 改为 **0.3**
3. **深度思考开关**：**关闭**
4. 其他参数保持默认（或按上表设置）

### 第 3 步：复制系统提示词
1. 打开 `COZE_CONFIGURATION_GUIDE.md`
2. 复制"系统提示词（System Prompt）"部分
3. 粘贴到扣子的"提示词"输入框

### 第 4 步：测试
1. 发送测试消息：
```json
{
  "function": "optimize_prompt",
  "userInput": "一只猫",
  "nodeType": "IMAGE_GENERATOR",
  "context": {
    "aspectRatio": "1:1"
  }
}
```
2. 检查返回的 JSON 格式是否正确
3. 检查是否有重复的关键词

### 第 5 步：获取 Bot ID 和 API 密钥

#### 获取 Bot ID（3 种方法）

**方法 1：从 URL 获取（最简单）✅**
1. 发布智能体后，查看浏览器地址栏
2. URL 格式：`https://www.coze.cn/space/xxx/bot/[bot_id]`
3. **bot_id 就是 URL 最后的那串数字**
   - 例如：`7234567890123456789`

**方法 2：从设置页面**
1. 点击智能体右上角"设置"
2. 找到"Bot ID"字段
3. 点击复制

**方法 3：从 API 管理页面**
1. 进入"开发" → "API 管理"
2. 在智能体列表中找到 Bot ID
3. 点击复制

#### 创建 API 密钥

1. 进入"开发" → "API 管理"
2. 点击"创建 API Key"
3. 填写名称：SunStudio AI Director API
4. **⚠️ 复制密钥**（只显示一次！）
   - 格式：`pat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

#### 保存到项目

在 `.env.local` 文件中添加：
```env
COZE_API_KEY=pat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
COZE_BOT_ID=7234567890123456789
COZE_API_BASE_URL=https://api.coze.cn/v1
```

## ❓ 常见问题

### Q1：为什么不选 Doubao-Seed-1.6-thinking？
**A**：虽然它推理能力最强，但：
- ❌ 思考模式强制开启，无法关闭
- ❌ 响应时间慢 2-5 倍（5-15 秒 vs 1-3 秒）
- ❌ 我们的任务（提示词优化）不需要深度推理

### Q2：为什么不选 Doubao-Seed-1.6-flash？
**A**：虽然它速度最快，但：
- ❌ 能力相对较弱
- ❌ 我们需要"质量优先"，而非"速度优先"
- ❌ Doubao-Seed-1.8 已经足够快（1-3 秒）

### Q3：重复惩罚为什么要设置 0.3-0.4？
**A**：
- 0：没有惩罚，AI 会重复相同的词汇
- 0.3-0.4：**最佳平衡**，避免重复但不影响质量
- 0.5+：惩罚过重，输出不自然

### Q4：深度思考为什么要关闭？
**A**：
- 开启：响应时间 5-15 秒
- 关闭：响应时间 1-3 秒
- 对于提示词优化任务，不需要深度思考

### Q5：如果 Doubao-Seed-1.8 不可用怎么办？
**A**：按优先级选择：
1. Doubao-Seed-1.6（标准版）
2. GPT-4o（国际版）
3. Claude 3.5 Sonnet（国际版）
