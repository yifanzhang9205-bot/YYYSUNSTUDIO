# 3D 相机提示词 - 最终方案

## 设计理念

### 核心逻辑
1. **锚定（Anchoring）**：输入图像 + UI 设置 = 绝对基准点
2. **空间分层**：远近 → 高低 → 角度（三维空间的自然理解顺序）
3. **微调矩阵**：9 个格子是围绕基准点的微小相机位移
4. **一致性锁定**：角色 ID、服装、光照完全锁定，只改变相机位置

### 空间维度定义

#### 维度 1：远近（Distance）
使用 Nano Banana 标准术语：

| 级别 | 术语 | 描述 | 视觉重心 |
|-----|------|------|---------|
| 1 | Extreme Close-Up (ECU) | 局部特写 | 纹理、情绪极度放大 |
| 2 | Close-Up (CU) | 头部特写 | 表情、面部细节、眼神 |
| 3 | Medium Close-Up (MCU) | 胸部以上 | 面部与部分服装 |
| 4 | Medium Shot (MS) | 腰部以上 | 角色动作与环境结合 |
| 5 | Medium Full Shot (MFS) | 膝盖以上 | 人物姿态、手部动作 |
| 6 | Full Shot (FS) | 全身 | 服装全身效果 |
| 7 | Long Shot (LS) | 人物占 1/2-1/3 | 人物与环境关系 |
| 8 | Extreme Long Shot (ELS) | 人物很小 | 宏大场景、氛围感 |

#### 维度 2：高低（Elevation）
使用电影摄影标准术语：

| 术语 | 描述 | 情绪效果 |
|-----|------|---------|
| High Angle | 俯视 | 脆弱、渺小 |
| Eye Level | 平视 | 中立、亲近 |
| Low Angle | 仰视 | 强大、威严 |

#### 维度 3：角度（Azimuth）
使用角色转身图标准术语：

| 术语 | 描述 | 适用范围 |
|-----|------|---------|
| Front View | 正面 | 0° - 30° |
| Front 3/4 View | 前四分之三 | 30° - 60° |
| Side View / Profile | 侧面 | 60° - 120° |
| Back 3/4 View | 后四分之三 | 120° - 150° |
| Back View | 背面 | 150° - 210° |

## 提示词模板

### 完整版本

```
IMPORTANT: Generate ONE SINGLE 21:9 image containing a 3×3 contact sheet grid.

[ROLE & TASK]
You are an expert CGI artist creating a character consistency contact sheet based on the provided INPUT IMAGE. Your task is to generate a single 21:9 image divided into 9 panels showing slight camera position variations around the base setup.

[CRITICAL CONSTRAINT: IMG2IMG FEATURE LOCKING]
Based strictly on the INPUT IMAGE, maintain perfect consistency across all 9 panels:
- Character Identity: LOCKED. EXACT same face, features, and expression.
- Outfit & Accessories: LOCKED. EXACT same clothing, colors, and textures.
- Lighting & Environment: LOCKED. Consistent lighting direction and mood.
- The ONLY variable: slight camera position shifts.

[OUTPUT FORMAT]
- One single 21:9 image with 3×3 grid (9 panels with thin dividing lines)
- Style: Professional contact sheet / camera test

[BASE ANCHOR POINT - Panel 5]
Distance: {DISTANCE_TERM}
Elevation: {ELEVATION_TERM}
Angle: {ANGLE_TERM}

This is your absolute reference. All other panels are micro-adjustments relative to this center point.

[CAMERA VARIATION MATRIX]
The 9 panels follow a spatial logic: Distance → Elevation → Angle

Panel 1: Slightly closer, camera elevated, rotated slightly left
Panel 2: Slightly closer, camera elevated, same angle
Panel 3: Slightly closer, camera elevated, rotated slightly right

Panel 4: Same distance, eye level, rotated slightly left
Panel 5: BASE ANCHOR - {DISTANCE_TERM}, {ELEVATION_TERM}, {ANGLE_TERM}
Panel 6: Same distance, eye level, rotated slightly right

Panel 7: Slightly farther, camera lowered, rotated slightly left
Panel 8: Slightly farther, camera lowered, same angle
Panel 9: Slightly farther, camera lowered, rotated slightly right

[SPATIAL INTERPRETATION]
- "Slightly closer/farther": Move one step in the distance scale (e.g., MS → MCU or MS → MFS)
- "Camera elevated/lowered": Shift from eye level to high/low angle (subtle, not extreme)
- "Rotated slightly left/right": Rotate 15-20° horizontally (e.g., Front → Front 3/4)

[RULES]
✅ Generate ONE image with 9 contiguous panels
✅ All angles are subtle variations, NOT drastic changes
✅ Maintain the illusion of rapid sequential photography
✅ Keep character pose, lighting, and environment identical

[NEGATIVE CONSTRAINTS]
❌ Do NOT change character pose between panels
❌ Do NOT change lighting direction between panels
❌ Do NOT generate 9 separate image files
❌ Do NOT introduce new elements not in the input image
❌ Do NOT make drastic angle jumps (e.g., front to back)
```

### 参数映射逻辑

#### 距离映射（cameraZoom: 0-10）
```typescript
const getDistanceTerm = (zoom: number): string => {
  if (zoom <= 0.5) return 'Extreme Close-Up (ECU)';
  if (zoom <= 1.5) return 'Close-Up (CU)';
  if (zoom <= 3) return 'Medium Close-Up (MCU)';
  if (zoom <= 4.5) return 'Medium Shot (MS)';
  if (zoom <= 6) return 'Medium Full Shot (MFS)';
  if (zoom <= 7.5) return 'Full Shot (FS)';
  if (zoom <= 9) return 'Long Shot (LS)';
  return 'Extreme Long Shot (ELS)';
};

// 微调偏移（相对于基准）
const getDistanceVariation = (zoom: number, offset: -1 | 0 | 1): string => {
  const adjusted = Math.max(0, Math.min(10, zoom + offset * 1.5));
  return getDistanceTerm(adjusted);
};
```

#### 仰角映射（verticalAngle: -30° to 60°）
```typescript
const getElevationTerm = (angle: number): string => {
  if (angle >= 20) return 'High Angle';
  if (angle <= -20) return 'Low Angle';
  return 'Eye Level';
};

// 微调偏移
const getElevationVariation = (angle: number, offset: -1 | 0 | 1): string => {
  if (offset === 1) return 'High Angle';
  if (offset === -1) return 'Low Angle';
  return getElevationTerm(angle);
};
```

#### 水平角度映射（horizontalAngle: 0-360°）
```typescript
const getAngleTerm = (angle: number): string => {
  const normalized = ((angle % 360) + 360) % 360;
  if (normalized < 30 || normalized >= 330) return 'Front View';
  if (normalized < 60) return 'Front 3/4 View (right)';
  if (normalized < 120) return 'Side View (right)';
  if (normalized < 150) return 'Back 3/4 View (right)';
  if (normalized < 210) return 'Back View';
  if (normalized < 240) return 'Back 3/4 View (left)';
  if (normalized < 300) return 'Side View (left)';
  return 'Front 3/4 View (left)';
};

// 微调偏移
const getAngleVariation = (angle: number, offset: -1 | 0 | 1): string => {
  const adjusted = ((angle + offset * 20) % 360 + 360) % 360;
  return getAngleTerm(adjusted);
};
```

## 九宫格生成逻辑

### 空间矩阵
```
┌─────────────────┬─────────────────┬─────────────────┐
│    Panel 1      │    Panel 2      │    Panel 3      │
│  距离: -1 档    │  距离: -1 档    │  距离: -1 档    │
│  仰角: +1 档    │  仰角: +1 档    │  仰角: +1 档    │
│  角度: -1 档    │  角度: 0        │  角度: +1 档    │
├─────────────────┼─────────────────┼─────────────────┤
│    Panel 4      │    Panel 5      │    Panel 6      │
│  距离: 0        │  距离: 0        │  距离: 0        │
│  仰角: 0        │  仰角: 0        │  仰角: 0        │
│  角度: -1 档    │  角度: 0 ★基准  │  角度: +1 档    │
├─────────────────┼─────────────────┼─────────────────┤
│    Panel 7      │    Panel 8      │    Panel 9      │
│  距离: +1 档    │  距离: +1 档    │  距离: +1 档    │
│  仰角: -1 档    │  仰角: -1 档    │  仰角: -1 档    │
│  角度: -1 档    │  角度: 0        │  角度: +1 档    │
└─────────────────┴─────────────────┴─────────────────┘
```

### 代码实现
```typescript
const generateCameraMatrix = (
  baseZoom: number,
  baseVertical: number,
  baseHorizontal: number
) => {
  const panels = [];
  
  // 距离偏移：上排近(-1)，中排基准(0)，下排远(+1)
  const distanceOffsets = [-1, -1, -1, 0, 0, 0, 1, 1, 1];
  
  // 仰角偏移：上排高(+1)，中排基准(0)，下排低(-1)
  const elevationOffsets = [1, 1, 1, 0, 0, 0, -1, -1, -1];
  
  // 角度偏移：左列左(-1)，中列基准(0)，右列右(+1)
  const angleOffsets = [-1, 0, 1, -1, 0, 1, -1, 0, 1];
  
  for (let i = 0; i < 9; i++) {
    const distanceTerm = getDistanceVariation(baseZoom, distanceOffsets[i]);
    const elevationTerm = getElevationVariation(baseVertical, elevationOffsets[i]);
    const angleTerm = getAngleVariation(baseHorizontal, angleOffsets[i]);
    
    let description = '';
    
    // 距离描述
    if (distanceOffsets[i] === -1) description += 'Slightly closer, ';
    else if (distanceOffsets[i] === 1) description += 'Slightly farther, ';
    else description += 'Same distance, ';
    
    // 仰角描述
    if (elevationOffsets[i] === 1) description += 'camera elevated, ';
    else if (elevationOffsets[i] === -1) description += 'camera lowered, ';
    else description += 'eye level, ';
    
    // 角度描述
    if (angleOffsets[i] === -1) description += 'rotated slightly left';
    else if (angleOffsets[i] === 1) description += 'rotated slightly right';
    else description += 'same angle';
    
    panels.push({
      number: i + 1,
      distance: distanceTerm,
      elevation: elevationTerm,
      angle: angleTerm,
      description
    });
  }
  
  return panels;
};
```

## 优势分析

### 1. 空间逻辑清晰
- 先确定远近（最直观）
- 再确定高低（第二直观）
- 最后确定角度（最复杂）
- 符合人类理解 3D 空间的自然顺序

### 2. 术语标准化
- 使用 Nano Banana 训练数据中的标准术语
- 避免 AI 无法理解的度数描述
- 提高生成准确性

### 3. 锚定机制强大
- Panel 5 是绝对基准
- 其他 8 个格子都是相对偏移
- AI 更容易理解"微调"而不是"绝对值"

### 4. 提示词精简
- 从 80 行减少到 40 行
- 去掉冗余的规则说明
- 重点突出，易于理解
